# Hoja de Vida

Plataforma para registrar y administrar hojas de vida (CV) y generarlas en PDF.

Es un proyecto de aprendizaje de Laravel, APIs REST, pruebas automatizadas y DevOps.

## Estructura

| Carpeta | Contenido |
|---|---|
| `api/` | Backend: API REST en Laravel 13 (se crea en la Fase 2) |
| `web/` | Frontend: tecnología por definir |
| `docs/` | Documentación técnica |

## Requisitos

- PHP 8.3 o superior con las extensiones `curl`, `dom`, `fileinfo`, `gd`, `mbstring`, `openssl`, `pdo_mysql`, `tokenizer`, `xml` y `zip`
- Composer 2
- MySQL 8.0 o superior
- Git
